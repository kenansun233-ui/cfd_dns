## 6. LaTeX 工程结构

主文件沿用 `hithesisart`：

```tex
\documentclass[fontset=fandol,toc=true,type=master,stage=opening,campus=shenzhen]{hithesisart}
```

正文使用独立文件 `body/report_shenzhen_master_opening.tex`，避免继续使用名称含 `doctor` 的示例文件。参考文献使用深圳校区样式：

```tex
\bibliographystyle{hitszthesis}
\bibliography{reference}
```

文内引用使用 `\cite{...}`，32 条 BibTeX 键保持稳定且语义化。图件采用相对路径，所有公式保持原生 LaTeX；进度表允许按模板自然分页。

## 7. 数据流与可复现性

迁移流程为：核验后的 Markdown 正文与图件 → 九段式 LaTeX 正文 → BibTeX 文献库 → `latexmk` 调用 XeLaTeX/BibTeX → PDF → 日志、引用和页面抽检。

正文迁移只改变章节归属、LaTeX 标记和必要的衔接语，不改变已核验公式、参数定义、数值和结论强度。图表编号由 LaTeX 自动生成并使用 `\label`/`\ref`。

## 8. 错误处理与保护

1. 目标目录写入前确认绝对路径位于 `E:\a开题报告`，并核对同名文件是否存在。
2. 模板、正文、图件或文献缺失时停止编译，不以占位符代替。
3. BibTeX 条目无法唯一转换时保留原著录信息并记录，不猜测缺失字段。
4. 编译失败时依据首个实质错误修复；不隐藏未定义引用、缺字或溢出警告。
5. hithesis 源仓库与 `paper_rewriting_output` 原成果保持只读，不执行覆盖或清理。
