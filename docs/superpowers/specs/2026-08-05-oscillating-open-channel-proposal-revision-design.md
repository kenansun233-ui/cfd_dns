# 振荡底壁开槽湍流开题报告保守修订设计

## 1. 目标与修订边界

本次工作审查并改进 `E:\cfdcode\paper_rewriting_output\final_paper` 中的硕士学位论文开题报告。修订采用“保守修订”路径：保留现有题目、学校规定的七章结构、以 DNS 为主和 PIV 为辅的总体路线、已有数据及“非平衡涡黏度模型”研究目标，但修复会影响科学成立性的确定性问题，而不把工作扩展为代码重构或新一轮数值研究。

用户确认的物理对象为有背景平均流的开槽流动：底壁沿流向作简谐振荡，顶部是真实自由表面；当前数值边界 `v=0`、`∂u/∂y=∂w/∂y=0` 解释为低 Froude 数、表面变形可忽略时的平坦自由表面（刚盖）近似，不再解释为完整槽道的中心对称面。

本次修订不修改 CUDA 求解器，不生成新 DNS/PIV 数据，不虚构误差阈值、实验参数、经费、文献或研究结果。凡现有证据不能支持的结论，改写为阶段性观察、研究假设、计划任务或待验证条件。

## 2. 已比较的修订路径

### 路径 A：实质性重构

允许改题、重构物理问题、缩减研究任务并重新设计工况矩阵。优点是科学闭环最强；缺点是会显著偏离现有开题框架和用户希望保留的研究路线。

### 路径 B：保守修订（采用）

保留题目、章节和主路线，同时修正构型、方程、参数、模型、证据和引用中的硬伤。优点是兼顾答辩可用性与现有工作延续性；代价是部分模型、PIV 和参数扫描只能给出明确的适用边界，不能包装成已经证明的创新。

### 路径 C：语言与格式润色

仅调整措辞和版式。工作量最小，但无法解决物理构型、整体动量约束、参数相关性和模型可预测性等核心问题，因此不采用。

## 3. 科学内容修订设计

### 3.1 物理构型

- 将“半槽道对称/自由滑移”“单侧振荡半槽道”等混合表述统一为“底壁流向振荡的开槽流动”或“平坦自由表面刚盖近似下的开槽湍流”。
- 明确 `h` 为水深，顶部边界是平坦、不可穿透、切向应力为零的自由表面近似。
- 增加 Froude 数 `Fr=U_b/sqrt(g h)` 及刚盖近似的适用说明；若没有自由表面位移数据，只说明该假设需要后续实验核验，不宣称已被验证。
- 明确周期 DNS、严格恒流量反馈与有限长度循环水槽并不完全等价。PIV用于相位平均速度、响应厚度和相位差的辅助一致性比较，不作为全部动量预算或闭合模型的独立验证。

### 3.2 控制方程与整体约束

- 将压力分解为均匀驱动和周期压力，例如 `p_total=-rho G(t)x+p'(x,y,z,t)`；瞬时方程只保留一种不重复的写法。
- 在相位平均动量方程中显式保留 `G(phi)`，并说明平面平均后的周期压力梯度如何处理。
- 给出恒流量条件 `h^{-1}∫_0^h <U>_phi dy=U_b` 及其整体动量约束。压力反馈与底壁剪切是由整体平衡联系的量，不再写成互相独立的响应。
- 把“黏性动量向湍流动量转换”改为“黏性与湍流动量通量的分配、相对贡献和交叉高度”。只有在增加机械能或 TKE 预算时才使用“输入—转换—耗散”语言。

### 3.3 参数体系与工况设计

- 以未振荡基准摩擦速度定义 `Re_{tau,0}`，把受迫工况的周期平均后验值记为 `Re_{tau,case}`。
- 以 `Re_{tau,0}`、振荡幅值（优先 `U_osc^+` 或 `beta`）和振荡时间尺度（优先 `omega^+`、`T^+` 或 `delta^+`）作为设计变量。
- 将 `Re_omega`、`Re_delta`、`delta/h` 等列为派生量，并显式给出它们之间的关系，删除“四参数联合解耦”的表述。
- 保留现有幅值扫描数据，但说明固定频率改变 `U_osc` 会同时改变多个派生量；后续频率组应以成对对照工况区分幅值效应和时间尺度效应。

### 3.4 非平衡涡黏度

- 第一层产出是 DNS 的复数表观涡黏度或频率响应函数，用于诊断应力—剪切幅相关系。
- 第二层才是低参数松弛闭合模型；必须规定参数化形式、训练工况、留出工况和回代方程。
- 同一工况逐点相除或拟合后再回代同一工况只算一致性重构，不算预测验证。
- 虚部表示正交相位响应，但不单独归因于“湍流记忆”；空间非局部性、结构对流和压力—应变等替代解释需在讨论中保留。
- 若留出工况不能优于准稳态基线，降级产出为“频率响应表征及模型适用边界”，不虚构普适模型。

### 3.5 数值与实验验证

- 把现有固定频率、仅改变幅值的五组零来流 Stokes 结果定位为边界幅相和线性缩放检查，不能表述为不同 Stokes 厚度下的网格验证。
- 正式 Stokes 验证计划应包含多频率剖面幅值/相位误差、有限水深影响以及网格和时间步收敛。
- 无振荡开槽基准除压力梯度外，还应计划比较 `U^+`、三分量脉动、雷诺剪切应力、总应力和谱尾。
- 统计长度由涡周转时间、积分自相关时间、批次均值和相位置信区间决定，不以固定周期数替代收敛判据。
- PIV 参数表至少规划 `U_b`、`f`、位移振幅、总行程、`delta`、`Fr`、视场、有效矢量间距、采样频率、相位样本数和不确定度；未知值明确标为后续设计输入，不补造数值。
